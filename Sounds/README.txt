把音频文件丢进这个文件夹就行。
双击桌宠时会随机播一个（文件夹里有几个就随机选几个）。

支持的格式
----------
  .wav          → 走系统 SoundPlayer（最稳）
  .mp3  .wma
  .m4a  .aac
  .flac .ogg    → 走 WPF MediaPlayer

分组
----
在这下面建子文件夹就是分组，**文件夹名 = 组名**：

    Sounds/
      菲比/
        打招呼.wav
        惊讶.wav
        晚安.wav
      菲比啾比/
        啾.wav
        啾啾.wav
      散装音效.wav          ← 直接放这里的算「（未分组）」

分完组之后：右键 → 双击音效 → 分组，勾哪几组就只用哪几组的音效。
不同角色的音效混在一起随机播会很出戏，分组就是解决这个的。

  · 组名和内容完全自定义，代码里没有任何写死的组名
  · 新建一个子文件夹 = 加了一组，不用重启（每次开菜单都会重扫）
  · 点菜单项不会关菜单，可以连着勾好几组；Esc 或点外面关闭
  · 「全选」是动作（把每组都勾上），它自己不打勾
  · 点一组就是纯粹的勾上/取消，不会影响别的组
  · 「全不选」= 双击只跳一下（会明确提示）
  · 空组也会列出来（建了组还没放文件时能看见），标着「（空）」

几个提示
--------
· 想调音量：右键 → 双击音效 → 音量…
· 想试听：  右键 → 双击音效 → 试听一个
· 重新扫描：右键 → 双击音效 → 重新扫描（放完新文件不用重启）
· 不想要音效了：右键 → 双击音效 → 取消「双击时播放音效」

文件夹为空时会回退成原来的「跳一下」，所以双击始终有反应。
如果勾选的分组里一个音频都没有，同样会跳一下，并提示你去检查分组。

注意
----
目前不支持 .mp4（那是视频容器，不是音频格式）。
如果你有 mp4 里的音频，需要先提取出来。
