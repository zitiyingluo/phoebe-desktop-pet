# 菲比桌宠 · Phoebe Desktop Pet

一个 Windows 桌面宠物，会聊天、能感知你在做什么、可以换装换人设。

.NET 8 + WinForms 单进程，**零第三方依赖**（不用 NuGet，不装任何包），
所有气泡/动画都是 GDI+ 手绘。

```
┌─────────────────────────┐
│  「oi」？你搁这儿喊魂呢？    │   ← 气泡（自绘，带尾巴）
└───────────────┬─────────┘
         ╭──────┴──────╮
         │   ( ˘ω˘ )   │      ← 立绘（可换装 / 睁眼闭眼）
         ╰─────────────╯
```

## 功能

### 桌宠本体
- 拖动时自然倾斜、单击挤压、双击播音效（没音效就跳一下）
- 待机时轻轻上下浮动
- 五档尺寸、总在最前、鼠标穿透、回到右下角
- 单实例互斥锁，不会开出两只

### 聊天
- 独立顶层窗口的输入框，**中文输入法正常**（不设 `WS_EX_NOACTIVATE`）
- 长期记忆：自动总结重要信息，也可手动编辑
- 历史持久化，重启不丢
- 「查看上下文」能看到这次究竟发了什么给模型
- 撞到 token 上限时**自动重说短一点**，不会给你半句话

### 主动发言
- 闲置一段时间会主动搭话，切窗口也会
- 有冷却和上限，不会没完没了
- 气泡还显示着时不触发

### 活动感知（隐私优先）
- **一般模式**：只读前台窗口标题 + 进程名，**不截屏**
- **深度模式**：默认**关闭**，开启后才截屏
- 截屏条件严苛：要同时满足 5 个条件（见下方「隐私」）
- 黑名单：进程名 + 标题关键词双向匹配，内置密码管理器/网银/无痕浏览规则
- 采集结果**只在内存，不落盘**；日志里**不记窗口标题**

### 隐私模式
- `Ctrl+Alt+P` 一键开启
- 开启后：不截屏、不采集、不主动说话、**立绘自动换成闭眼**

### 可扩展
- **换装**：往 `Art/` 丢图片，文件名就是菜单名
- **人设**：往 `Personas/` 丢 JSON 人设卡，可切换（自带两套）
- **音效**：往 `Sounds/` 丢音频，子文件夹名就是分组，可多选可试听

### 其他
- 用量统计（估算花费）、余额查询
- 日志轮转（`pet.log` → `.1`）

## 快速开始

### 1. 环境
需要 **.NET 8 桌面运行时**（不是系统自带的，要单独装）：

https://dotnet.microsoft.com/download/dotnet/8.0

选 `.NET 8.0` → `Desktop Runtime` → `Windows` → `x64`

### 2. 构建

```powershell
# 停掉正在运行的实例（否则链接会失败）
Get-Process -Name dotnet -ErrorAction SilentlyContinue | Stop-Process -Force

# 编译
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1

# 跑自检（基线 500 PASS）
dotnet PhoebePet.dll --selftest
```

> `build.ps1` 直接调用 SDK 自带的 Roslyn（`csc.dll`）+ `build.rsp`，
> **完全绕过 MSBuild 和 NuGet 还原** —— 所以离线也能编译。

### 3. 运行

```powershell
.\start-pet.cmd
```

### 4. 配置 API Key

复制模板并填入你自己的 Key：

```powershell
Copy-Item chat-config.example.json chat-config.json
# 然后编辑 chat-config.json，把 "ApiKey": "" 填上
```

> 程序首次运行也会自动生成 `chat-config.json`（Key 为空）。
> **不填 Key 也能用**，只是不能聊天 —— 拖动、换装、音效都不需要联网。

想换别的服务商（Kimi / 智谱 / Ollama 等），改这三个字段即可，
只要对方兼容 OpenAI 接口格式：

```json
{ "BaseUrl": "https://api.moonshot.cn", "ApiKey": "sk-xxx", "Model": "moonshot-v1-8k" }
```

## 隐私

这个项目的设计原则是**宁可少做，也不越界**。

### 截屏的 5 个条件（必须全部满足）

1. 「活动感知」开启（默认开）
2. 「深度模式」开启（**默认关**）
3. 不是隐私模式
4. 当前窗口不在黑名单
5. **且**属于以下之一：
   - 它要主动搭话时
   - 你在聊天里明确让它看画面时

第 5 条的判据是「指示词 + 征求看法」：

```
会截屏：「你看这个好不好看」「看我这张图怎么样」
不截屏：「我今天好累」          ← 没有指向画面
```

设计上**宁可漏判也不误判** —— 没被要求就偷偷截屏是隐私问题。

### 其他保证

- 只截**前台窗口**，不是整个桌面
- 缩到 512px 长边、转 JPEG 后发送
- 图片**只在内存，不写磁盘**
- 日志里**不记录窗口标题**
- 随时可用菜单「看看菲比看到了什么」自查

### 请注意

- 窗口标题和截图**会发送给模型服务商**（这是功能本身）
- 黑名单**不能保证 100% 覆盖**，敏感场合请直接开隐私模式
- 聊天历史、长期记忆以**明文**存在本地

## 费用

按默认配置（`deepseek-chat`）估算，单次对话约 **0.001 元**：

| 强度 | 每月 |
|---|---|
| 轻度 | ~1 元 |
| 中度 | ~2-3 元 |
| 重度（全天挂机） | ~6 元 |
| 全天挂机 + 频繁截图 | ~15 元 |

省钱机制默认已开：上下文自动截断、记忆总结用便宜模型、限制回复长度。

> 换更贵的模型（如 pro 档）成本会涨 4-5 倍。

## 开发者文档

### 项目结构

| 文件 | 职责 |
|---|---|
| `pet.cs` | 主窗口、菜单、渲染、全部自检 |

| `sound.cs` | 音效播放与分组 |

| `inputbox.cs` | 输入框（独立顶层窗口） |
| `bubble.cs` | 气泡绘制（自绘，分层窗口不能放控件） |
| `balance.cs` | 余额查询 |
| `art.cs` | 立绘换装 |
